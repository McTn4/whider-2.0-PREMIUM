¿Cómo se instala?
Windows
Abre el instalador. Si Windows muestra «Windows protegió su PC», pulsa «Más información» y después «Ejecutar de todas formas»: aparece porque la app todavía no está firmada con un certificado de pago.
macOS
Abre el archivo y arrastra WHIDER a Aplicaciones. La primera vez, ábrela con clic derecho → «Abrir».
Linux
Dale permiso de ejecución (Propiedades → «Permitir ejecutar como programa», o chmod +x) y ábrela.
